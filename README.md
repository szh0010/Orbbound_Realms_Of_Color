# 斗球大陆: 夺彩之战

在很久以前，斗球大陆是一个充满色彩与生机的世界。

然而，邪恶的反派们夺走了世界的颜色，将大陆变成一片灰白。作为唯一仍拥有纯净力量的白球，玩家将踏上冒险之旅，击败一个又一个反派，夺回被夺走的色彩，让世界重新焕发生机。

## 游戏简介

《斗球大陆：色彩归还之旅》是一款第三人称 3D 动作冒险游戏。

玩家将控制白色小球，在不同关卡中探索、跳跃和移动，与敌人战斗，逐步恢复世界的色彩。

## 核心玩法

- 探索灰白的斗球大陆
- 击败夺走色彩的反派
- 通过传送光圈进入冒险区域
- 找回世界中失去的颜色
- 操控小球移动、跳跃和转向
- 体验出生动画、光柱、粒子和发光效果

## 操作方式

| 操作 | 功能 |
| --- | --- |
| W / A / S / D | 前后左右移动 |
| 鼠标移动 | 控制镜头与玩家转向 |
| 空格 | 跳跃 |
| Esc | 释放鼠标光标 |

## 游戏目标

玩家需要不断前进，击败各个区域的反派，并夺回他们所占有的颜色。

随着冒险深入，原本灰白的世界将逐渐恢复：

- 红色的火焰
- 蓝色的天空与海洋
- 绿色的森林
- 黄色的光芒
- 更多未知的色彩

最终，让斗球大陆重新成为一个充满生命力的世界。
